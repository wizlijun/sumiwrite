# RimeKit 内嵌输入法 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 rapp 的内嵌 Rime 输入法拆成本机共享包 RimeKit,挂到 Sumi Write(`apps/ios/`)的正文编辑面上:接实体键盘时打拼音由内置雾凇接管,组字在光标处带下划线,候选行盖住下一行。

**Architecture:** RimeKit 是独立的本地 git 仓库 `/Users/bruce/git/rime-kit`(SwiftPM:`CRime` 头文件、`RimeKeys` 纯 Swift 按键策略、`RimeKit` 引擎 + 无界面框架的输入控制器 `RimeInput`、`RimeKitUI` UIKit 候选行 + `UITextView` 适配器)。代码从 rapp `gui/packages/rapp_rime/ios/rapp_rime/`(rapp 提交 5d482e6b)逐行搬,只去掉 Flutter 通道。Sumi Write 经 XcodeGen 本地包引用它,`SumiTextView` 的按键先交给适配器,组字用 `setMarkedText` 走编辑面已有的组字路径。

**Tech Stack:** Swift 5.9 / SwiftPM、UIKit + TextKit 2、librime 1.16.1(LibrimeKit-iOS v0.2.2 静态 xcframework)、雾凇 927e1cf、XcodeGen、XCTest。

**Spec:** `docs/superpowers/specs/2026-11-20-rime-kit-design.md`(先读 §0 修订,冲突时以 §0 为准)。rapp 侧设计:`/Users/bruce/git/rapp/docs/superpowers/specs/2026-11-20-rapp-ios-rime-ime-design.md`(只读)。
